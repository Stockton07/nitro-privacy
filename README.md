# Nitro Privacy Policy

This repository contains the public privacy policy for **nitro - Work and Payroll**.

Privacy and account-deletion requests are directed to `stockton@nelson-it.com`.

## Publish with GitHub Pages

1. Create a new public GitHub repository named `nitro-privacy`.
2. Add `index.html` and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public URL to enter in App Store Connect.
